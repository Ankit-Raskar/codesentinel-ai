# CodeSentinel AI

AI-powered pull request review platform that helps engineering teams detect bugs, security vulnerabilities, performance bottlenecks, and risky code changes before merge.

## Live Demo

https://codesentinel-ai-gules.vercel.app/

---

# Features

- AI-powered pull request reviews
- Security vulnerability detection
- Performance issue analysis
- Merge safety scoring
- Interactive demo repositories
- Step-by-step AI review workflow
- AI engineering assistant chat
- Repository & PR management UI
- Streaming AI review experience
- Realistic demo mode for hackathons
- Modern dark SaaS interface
- Responsive design

---

# Demo Workflow

The platform provides a guided review experience:

1. Choose a repository
2. Select a pull request
3. Run AI Review
4. Watch live AI analysis
5. Review vulnerabilities & findings
6. Chat with AI assistant

# Environment Variables

Create a `.env` file:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_PUBLISHABLE_KEY=your_supabase_key
VITE_GROQ_API_KEY=your_groq_api_key
```

# Installation

Clone the repository:

```bash
git clone https://github.com/your-username/codesentinel-ai.git
```

Go into the project:

```bash
cd codesentinel-ai
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

---

# Build for Production

```bash
npm run build
```
